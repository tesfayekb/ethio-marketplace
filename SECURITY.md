# Security policy

## Reporting a vulnerability

Please report security vulnerabilities privately, through GitHub's
**Report a vulnerability** form on this repository (the **Security** tab →
**Advisories** → **Report a vulnerability**). Private vulnerability reporting
is enabled for this repository.

**Do not open a public issue, discussion or pull request for a vulnerability.**
Public reports put users at risk before a fix is available.

## What to include

- A description of the issue and the impact you believe it has.
- The affected page, endpoint, file or component.
- Steps to reproduce, or a proof of concept, using only your own accounts and
  data.
- Any logs, screenshots or requests that help us confirm it.
- Whether you want to be credited, and how.

## What happens next

Every report is acknowledged. We investigate it, keep you informed of progress
through the private advisory, and tell you when a fix has landed.

## Bounty

There is no bug bounty program. We are grateful for responsible reports.
