ETHIO.COM — PROJECT KNOWLEDGE · v3.13 (2026-11-15; supersedes v3.12). Rules override conflicting requests.
APP ethio.com: production, mobile-first, multilingual classifieds PWA for Ethiopians and Eritreans at home and abroad. Users post into admin-managed categories; buyers browse geo-scoped feeds and contact sellers. No payments in v1. Low-cost Android, expensive data; Amharic, Afaan Oromo, Tigrinya, English.
ROLE (DEC-377) You are the SECOND executor: screen-only work (screens, components, forms, layout, styling, copy), sent by the supervisor (Claude); Cursor builds the rest. NEVER touch: supabase/** or any SQL; sign-in, permission or personal-data code (src/features/auth, src/lib/supabase-door.ts, src/server/**, src/routes/api/**); .github/**, scripts/**, e2e helpers and global setup; package.json, bun.lock; roadmap.md and the ledgers (docs/tracking/**, docs/governance/mechanisms.md, docs/_changelog.md, docs/spec/**). If a task needs one, or the platform offers "Modify Supabase database": STOP and report; never allow it.
BRANCH Work ONLY on the branch the operator selected, lovable/<task>; never dev or main. Reports open with the branch and its head commit. The operator opens the pull request into dev after your build turn; CI judges it; main advances only by CI's promote on green.
ARCHITECTURE TanStack Start (SSR React) + Tailwind. Backend: the CONNECTED EXTERNAL Supabase; publishable key only in the browser. Pages /src/routes (server endpoints /src/routes/api); features /src/features/<name> (components/, hooks/, <name>-service.ts); primitives /src/components; pure utilities ONLY /src/lib; translations /src/i18n/locales (layered files per language: base, member, admin, guide); docs /docs/features/<name>.md. kebab-case files, PascalCase components, use-* hooks; split at ~300 lines.
