## 2. The Edit — four changes to the wizard, nothing else
A. **A mode.** `wizard` takes `mode: "post" | "edit"` (and, for staff, `actor: "seller" | "admin"`). In edit mode the draft hook is `useEditDraft(listingId, actor)` — the same interface as `useDraft` (`values`, `photos`, `refusals`, `saveState`, `change`, `saveAt`, `goTo`, `step`…) so every step screen renders unchanged — loaded from the ad (the seller: `my_listing` + the editable fields it already returns; staff: the admin's read); no autosave (`change` updates the screen only); `saveAt(step)` builds that step's change set (the fields of that step whose value differs from the ad's — the `editChanges` rule of E2b, per step) and sends it through the edit door; an empty change set saves nothing and just returns; the door's refusals land under their fields as the wizard already draws them; `saveState` reads saved / saved and sent for review / not saved (D192 toast, §3).
B. **The Review in edit mode.** The Category section shows its value with no Edit link (and the step strip's step 1 is not a link); every other section keeps its Edit link and the "Edit comes back" behaviour as built; the primary action reads "Done" and returns to the ad's page (the seller) or to where staff came from (§2D); the "In review" box and the publish-time texts are not shown; the preview under the sections (`ListingPreview`) is the ad as it stands after the saves.
C. **The entry.** The seller's Edit (the row menu, the ad page's bar) opens `/my-listings/<id>/edit` — the wizard in edit mode on its Review step; the `?edit=1` panel and the stacked boxes go. A closed, refused or live ad is editable as today (`EDITABLE_STATUSES`); a draft opens the posting wizard as today.
D. **Staff.** Screening's preview "Edit" and the console's "Edit" open `/admin/listings/<id>/edit` — the same wizard, `actor: "admin"`: the Review shows a reason box (required before any step's Next; the note optional) above the sections — DEC-173's reason, asked once for the sitting, sent with every step's save; the door is `admin_edit_listing` under the step-up gate as today; "Done" returns to the queue with the ad's preview re-opened (from Screening) or to the listing page (from the console); from Screening the Review's footer also carries Approve and Reject (D188: "after edit we can approve or reject"), with E3b's at-once refresh of the preview kept.

Removed with it: `ListingEditForm` and its boxes (edit-form.tsx), the panel in my-listing-page.tsx, the edit panel in screening-page.tsx, the `editAdminListing` call sites that the wizard replaces, their docs sections; the `edit_my_listing` and `admin_edit_listing` doors stay as they are (the wizard sends the same change sets).
