## 2. THE LAW — a proof's verdict never depends on how its file is carried (INC-1056, INC-1089)

Every text a proof or pre-check compares against `pg_proc.prosrc` (or any live text) is normalised on BOTH sides with `replace(…, chr(13), '')`, and no string literal a proof compares is written across a raw line break in the file: a line break inside a compared fragment is written as `chr(10)` (`',' || chr(10) || '    ''caps'', public.listing_caps(v_row.id)'`) or as an `E'…\n…'` escape, so the literal sits on one line of the file. A literal that spans lines is the defect, wherever it is in a DO block. The paste path (ethio-staging today, ethio-prod always — INC-1043) carries CRLF; the CLI and CI carry LF; a landed body applied by paste holds CR in `prosrc`, which is why every live-side read strips it.
