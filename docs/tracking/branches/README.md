# CI evidence per ref (DEC-321)

On branch `ci-evidence`, `docs/tracking/branches/<ref>/` holds the evidence of the runs that tested a ref other than `dev` — a lane's `ci-status.md`, `guards-last-failure.md`, `e2e-last-failure.md`, `local-backend-proof.md` and the rest, each at its own name — while `dev`'s runs keep publishing at `docs/tracking/<file>`. `scripts/publish-evidence.sh` maps every file by the run's `EVIDENCE_REF` (the ref sanitised to `[A-Za-z0-9._/-]`; a ref that could name a path outside this folder is refused). The flake ledger stays one file, `docs/tracking/flake-ledger.md`, for every ref, and each of its lines names the ref. A ref's folder is removed by hand once its lane has merged (a records-turn line). This copy on dev describes the folder; the evidence itself lives only on `ci-evidence`.
