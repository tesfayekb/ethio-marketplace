# The ad page (D201)

The page `/l/<words>-<public_id>` is built in bundle 19 (the spec: Project record D201 v1, 2026-10-17; the study of 2026-10-16). This turn lands the address rules and the QR route only.

## The address

The public id is ten characters of `23456789abcdefghjkmnpqrstuvwxyz`, generated by the database at insert; this lands with M1 in turn 3. The canonical address is `/l/<words>-<id>`, with the words from the title's ASCII fold (≤ 60 characters) and a 301 to the canonical when the words differ. `/l/<id>` alone also resolves and is what the QR carries; these page resolutions arrive in a later turn.

`/l/<id>/qr.svg` lands this turn: an immutable SVG from `qrcode-generator` 2.0.4, server-only, validated by id shape, with no database read. It carries the request origin's short address `/l/<id>`.
