# DEC-459 (c), INC-1278 — the failure crawl's allowlist (e2e/helpers/failure-crawl.ts).
# Grammar: `key | reason | until` — until is a date, an INC or DEC number, or `permanent`.
#   page <route>              a page route the crawl does not open
#   footer <key>              a footer item with no page yet (DEC-463)
#   read <route> <read key>   a read whose failure the page meets by design, with no notice
#   read <route> <read key> (<forced>)   one forced failure of that read only
#   read <route> as <audience> …   either of the two, for that audience only
#   read * <read key>         a shell-wide read on every page (asked on some loads only, so
#                             no one page calls it stale)
#   default <file> <function> a designed default the crawl does not meet on a page's load
# The census (scripts/conformance/failure-crawl.ts) fails a stale `page`/`footer`/`default` line
# and a `read` line of a route the crawl does not open; the crawl fails a `read` line its page
